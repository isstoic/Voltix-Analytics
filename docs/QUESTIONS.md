# Analytical questions this project answers
**Sales:** Which categories/channels/regions generate the most revenue and profit? Is growth from more orders or higher AOV (exact decomposition)? Which regions are growing/declining? Do discounts raise margin or erode it? How much reported revenue do refunds remove?
**Product:** Which SKUs drive profit (Pareto)? Which popular SKUs have weak margins? Which have unusually high return rates and what is the refund impact? Which categories lean on discounts?
**Customer:** Do customers return? Which cohorts retain best? Who is at risk (RFM)? Which segments contribute revenue? How concentrated is value in top customers?
**Marketing (simulated):** ROAS, CAC, cost per order by channel; how ROAS differs from ROI; what data is needed for real attribution.
**Operations:** Which SKUs risk stockout or hold excess stock (simulated)? How reliable is delivery and does lateness hurt reviews (real)?
